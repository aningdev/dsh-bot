# 02：创建 Bot、唯一对话与重开恢复

**What to build:** 用户创建 Bot，补齐已安装模板、默认模型和工作区后，首次打开自动初始化唯一对话，发送文本并看到流式回复；重开恢复原对话和本地草稿。

**Blocked by:** 01：NSH 连接官方 dsh web 的真实协议闭环。

**Status:** done — 本地实现与真实 NSH / 官方后台验收通过；范围和审查修复见 [验收记录](../EVIDENCE.md)。未发布 GitHub。
