# 04：共享模型与凭据设置、当前对话模型切换

**What to build:** 用户在桌面设置共享供应商、端点、模型目录和机密；Bot 初始化前选择默认模型，初始化后查看并切换当前模型。

**Blocked by:** 02：创建 Bot、唯一对话与重开恢复。

**Status:** done — 本地实现与真实 NSH / 官方后台验收通过；范围和审查修复见 [验收记录](../EVIDENCE.md)。未发布 GitHub。

- [x] 从公开可配置供应商目录关联 settings schema，支持已适配字段，对不支持的字段明确提示。
- [x] 设置带 revision，只写编辑字段；冲突保留草稿并重新读取，不能覆盖脱敏占位值。
- [x] credentials 仅写入/移除与读取脱敏状态，密钥不进入本地文件、日志或 Bot；提交后清空机密输入。
- [x] 分步保存分别报告成功/失败，不假定 settings 与 credentials 事务原子性；失败不自动删除被引用凭据。
- [x] 默认模型只用于初始化；恢复读取后台当前选择，不隐式双向同步。
- [x] 当前模型从下一步骤生效，已经准备的步骤保留旧选择；说明切换可能异步保存后台默认值。
- [x] 模型目录暂不可读与供应商/密钥/模型不可用分开呈现，保留原选择，不静默回退。
- [x] 使用实际公开 remote 验证配置冲突、凭据失败和模型切换；独立测试服务不等于真实供应商验收。

来源：已确认的产品蓝图、架构，以及[实施规格](../SPEC.md)。
