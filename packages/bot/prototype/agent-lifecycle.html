Bot 配置保存与 Agent 生命周期

原型 · 不是生产代码。用一个可点的状态模型检查：用户保存 Bot 配置的同时又存在执行、待处理输入、上下文压缩和冷恢复请求时，Bot 服务到底允许发生什么。

要回答的问题 保存 Bot 配置要求「没有执行、也没有待处理输入」，而销毁旧 Agent 会取消并清空 inbox。但停止执行会保留待处理输入，维护期又占用真正的空闲窗口，读取历史还会触发冷恢复。这四种情况交错时，哪些操作应立刻生效、哪些必须排队、哪些必须明确拒绝？客户端在这个过程中应该看到什么？
