# UI 包边界

修改组件、样式或默认文案前，阅读并遵循 [界面设计与文案规范](../../docs/UI_GUIDELINES.md)。

- 本包只拥有 React DOM 基础组件、通用展示组件和视觉 Token；Bot 业务、应用路由、原生能力和主题偏好管理归消费者。
- shadcn 组件通过包内配置与脚本维护；修复保留可更新性，不在应用中复制实现。
- 设计 Token 统一维护在 `src/styles/globals.css`。包内导入使用相对路径或 `@dsh-bot/ui`，不依赖应用别名。
- 修改样式扫描路径时，以 CSS 文件所在目录为基准；迁移后验证应用成品上的样式和交互。
