## 已实现能力

- **执行与所有权**：通过固定版本 npm 包启动独立 Runner；Bot 独占 Agent 生命周期，标准 Session API 通过统一委托和操作租约参与冷恢复、读取及执行。配置事务对同一 Session 生效，未完成事务在重启后保留故障状态，阻止误执行。
- **桌面工作台**：创建、列表、持续聊天、历史、工具活动、单次允许或拒绝审批、排队与追加输入、停止执行及独立撤回。Renderer 经受控 IPC 到 Main，再连接 Runner。
- **配置与凭据**：模板复制为独立配置；配置保存返回已生效或明确拒绝原因；API 密钥在执行侧保存，桌面不能读回已存密钥。正式工作区模板装配上游文件和命令工具。
- **后台与交付**：用户级 launchd 安装、启停、状态、卸载和可选登录启动；关闭桌面后后台继续运行，重开恢复连接。成品携带 Node 24.15.0 和生产依赖，支持迁移路径启动、先停机再替换运行时，以及中断状态与保留输入的恢复。
