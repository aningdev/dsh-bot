# NSH 界面规范

适用于 apps/client，替代旧 Electron/shadcn 界面规则。

- macOS 主界面固定为左侧 BotList、中间 BotChat、右侧 BotInfo；会话入口位于 BotChat 顶部。
- BotChat 只呈现用户文本和 Agent 文本，支持流式回复。不提供工具结构、审批卡片或推理详情。
- 文案使用一致的产品术语，按钮描述操作，状态说明真实结果；仅保留必要错误原因和恢复提示。
- 使用 NSH 原生组件与统一主题；遵循系统外观，保持清晰字号、间距、焦点和可访问名称。
- 用布局与留白表达层级，避免装饰动画和无必要卡片。
- 空状态、连接中、断线、执行中、中断、失败和提交结果未知均须如实表达。
- 简单界面不改变后台权限；隐藏执行详情不能默认允许工具。
- 平台能力放在客户端 platform 模块，页面通过连接模块操作后台。
