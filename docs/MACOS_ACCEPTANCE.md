## 证据范围

- **服务契约**：真实 Harness Host、公开 Bot/Session API、JSONL 持久化和确定性模型。它验证行为与失败边界，不代替人工安装。
- **成品 E2E**：本次构建的 Electron 应用，经 renderer → oRPC → Main → Runner；模型为测试适配器。launchd 用例操作真实用户 job，登录用例只验证配置副本与状态。
- **真实模型与界面**：既有本机正式 profile、随包 Node、DeepSeek 回复和工具探针，以及 Cua 操作桌面审批的结果。它们不等同于干净目标机。
- **新 ZIP 安装复核**：解包分发 ZIP、复制到用户 Applications、全新 profile，使用 Cua 启动。已完成首次自动安装后台、创建并列出 Bot、退出后 Runner 保持、重开读回同一 Bot 与列表、停止后台后重开仍停止；由此发现并修复了停止态界面无限加载（见下方记录）。剩余的新包复核项受当前锁屏限制。
