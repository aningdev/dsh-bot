# dsh-bot 产品蓝图

本文描述从零重建的产品目标与业务规则，不描述实现路线：装配方式、文件格式、运行时安装与传输细节见[架构文档](ARCHITECTURE.md)，当前进度见 [README](../README.md)，概念定义见[术语表](../GLOSSARY.md)，上游证据见 [docs/research](research/)。旧版 Electron 产品规则已被本次决定替代。

## 产品定位

dsh-bot 是支持持续对话与工作跟进的本机 Agent 工作台。用户选择具名 Bot，提交输入、查看回复并跟进工作目标。桌面 UI 是控制端，独立后台管理配置、工作区与执行状态；关闭或退出 UI 不停止已接纳的工作，但遇到审批时可能等待用户重连。后台运行在系统设置中应明确归属于本 App，以可识别的应用名称和图标呈现，让用户能够识别和管理后台活动。

首版通过持续对话跟进目标，目标是否完成由用户在交流中判断；不提供独立目标列表、完成按钮或目标状态存储。

## 对话模型

每个 Bot 只有一个持续对话入口，对应一个持久执行会话，不提供新建或切换会话的操作。首次打开时检查初始化条件，满足后自动初始化；未就绪或初始化失败时保留 Bot 信息和草稿，提供具体修复入口。结果未确认时先核对，不盲目重试创建。

已有对话恢复失败时，区分连接失败、模板缺失或无效、历史损坏与会话不存在，提供“重新检查”和故障原因。读取失败不清空对话指针，不自动新建、重置或重新绑定会话；无法恢复时可以另建 Bot，原 Bot 保留记录。

## Bot 与工作区

Bot 拥有稳定 ID、名称、归档状态、所选模板、默认模型和工作区。可以先创建 Bot，再补齐后台、模型、模板与工作区条件；条件满足后才初始化和发送。缺少兼容后台、可用模型或有效目录时分别引导修复，不静默替换目录、模板或模型。

模板与工作区在首次初始化时固定，之后需要不同组合就新建 Bot，原 Bot 保留历史。名称和归档状态仍可修改。模板决定指令与工具选择：运行中的执行实例保持已装配的模板组合，后台重启后按原模板标识使用当前定义；模板缺失或无效则显示故障，不自动替换。产品不承诺永久保留旧模板实现。

每个 Bot 自动分配稳定默认工作区，也可以在初始化前指向外部项目目录。多个 Bot 可以使用同一目录，文件不会自动复制，也不提供并发隔离。工作目录不构成路径权限或操作系统沙箱。

归档停止接收新输入，并从默认列表隐藏 Bot；用户仍可查看历史、处理既有审批、撤回待处理输入和取消归档。已接纳的输入和正在运行的工作继续按原规则处理，归档区仍显示未结束的工作。取消归档后继续原对话。

首版只提供归档与取消归档，不提供永久删除 Bot、清空历史或清理工作区的入口。数据默认保留；归档不删除历史、不清理磁盘，也不取消执行。

## 指令与 Bot 记忆

首版使用模板指令与上游工作区指令机制，不提供独立的 Bot 指令编辑、文件重载或内容快照管理；工作区指令按上游刷新规则生效，不承诺整个对话固定不变。

后续独立指令功能的目标是：内联内容与独立文件二选一，显式重载文件并保存当时生效的内容；已有执行不自动追随编辑，空闲时显式应用。内容快照不冻结能力代码、凭据或全局设置。

Bot 记忆也列为后续目标：按稳定 Bot ID 维护用户可查看、编辑和清空的长期事实，与对话历史及自动摘要分开；保存携带版本号，拒绝过期编辑；每次模型请求最多注入 2,000 个字符，来源与更新时间可见。自动整理、历史检索与自动写入另行设计。这些要求不属于首版验收。

## 配置所有权

配置分为后台设置、Bot 注册表与界面偏好，各自只有一个真源。

模型供应商、服务地址、模型目录与凭据由后台管理。桌面提供自己的“模型与凭据”设置页，通过上游配置接口读取脱敏视图、保存修改；密钥提交后不再回显，也不保存在客户端文件中。保存失败保留仍需编辑的内容并展示错误；遇到配置冲突先重新读取，由用户确认后再保存，不能静默覆盖。

Bot 初始化前选择默认模型，未显式选择时使用后台默认值；初始化后，信息区显示并切换后台记录的当前对话模型。Bot 默认值与当前模型不隐式双向同步，恢复对话时以后台记录为准。模型切换从下一个执行步骤生效，已准备的步骤继续使用原模型选择；界面说明这一范围。

模型选项来自后台目录，供应商、端点与密钥在 Bot 之间共享。供应商被禁用、密钥被移除或模型不可用时保留原选择、明确报错，由用户修复或手动选择，不静默回退。目录暂时不可读与后台明确拒绝该模型分别呈现；已有历史仍可查看。共享配置的生效时机由上游提供方决定。

Bot 注册表由桌面独占写入，保存名称、模板引用、工作区、默认模型与会话指针；移动端只读快照。主题、窗口和本地选择等偏好由界面单独保存。

模型配置不另建存储，也不直接改写后台配置文件。环境变量保留给引导与自动化使用，产品设置页通过后台接口完成保存。

## 输入、目标与状态

客户端在发送前保存稳定请求标识与正文，用于核对后台是否接纳；网络超时不能推断为未接纳。界面区分本机草稿、发送结果待确认、已接纳等待处理、执行中与执行结束；执行结束不代表工作目标完成。

普通发送统一排到当前轮次结束之后，展示待处理列表和“已接纳，等待处理”。首版允许撤回尚未领取的消息，不提供“立即插入当前执行”；是否仍可撤回以后台为准。

发送结果不明确时，单独显示“发送结果待确认”并保留正文，提供“重新核对”和“复制内容”。不自动重发，也不提供一键重试未确认输入。用户修改后再次发送属于新输入，须提示前一条仍可能已接纳。普通草稿与待确认输入保存在桌面本地，结果确认后清理相应的临时核对记录，不保存密钥。

UI 断线不停止执行。停止当前执行、撤回待处理输入与停止后台是三项独立操作。“停止”请求取消当前执行；请求确认只表示后台已接纳取消，是否停稳由后续执行状态判断。尚未领取的消息继续保留，可逐条撤回，通常等待下一次新输入唤醒。再次发送时提示已有消息将按顺序继续；停止期间其他客户端的新输入也可能唤醒执行，因此停止不等于持续暂停或清空队列。失败、中断与未确认结果必须准确展示。

首版只交付纯文本输入。附件作为后续独立阶段，须一并验收上传失败、模型能力检查、未确认附件的保留与恢复。附件的完整用户消息会持久化在本机，包含文本附件正文与图片数据，用于上下文重建与恢复；聊天投影只保留输入与附件名称、类型，不含附件正文或图片字节。选择附件时须告知这一持久化行为。

## 界面

客户端采用三栏：Bot 列表、对话、Bot 信息。普通消息区只展示用户消息与 Agent 文本，支持流式输出，不展示工具结果卡片与推理过程；待处理输入和未确认输入有明确状态。

需要授权的调用显示工具名称、操作摘要与关键目标，例如命令、路径或域名，并提供允许和拒绝；详细参数按需展开。摘要依据后台请求生成，不能只显示缺少授权对象的按钮。审批是普通消息展示规则之外的必要操作界面。

用户退出后，后台遇到审批可以等待重连；恢复后显示“等待审批”，拒绝、取消或失效后及时更新。首版不增加常驻自动审批端，也不假定统一审批超时。

## 能力与扩展

能力由 Bot 初始化时选定的模板决定。内置模板随上游发行版提供，用户可以按上游流程安装自建模板；首版只选择和展示已安装模板，提供自建流程说明，不提供模板编辑器或逐项能力授予。模板安装和修改属于共享后台配置变更，重启影响遵循已确认的模板规则。

工具随模板启用，需要授权的调用由用户允许或拒绝；拒绝不扩大授权，缺少审批界面不能默认放行。不支持远程或凭据型工具服务、多租户与服务端部署；外部工具进程不视为操作系统沙箱。计划模式不在本轮范围。

## 多端目标

未来桌面与 iOS/Android 客户端通过独立 Relay 跨网络同步。手机只发送和展示对话，不打包后台、不安装运行时、不运行执行引擎；移动端的密钥与令牌只存内存，每次冷启动重新验证，不写入安全存储或其他持久化位置。模型密钥只留在后台，多端通信不改变后台对执行状态的权威归属。

Bot 列表与 Bot 设置只在桌面创建和修改：手机只读取桌面给出的只读快照来展示与选择，新建或改名一律回到桌面。模型供应商和凭据同样由桌面管理，移动端只使用已配置的模型进行对话。多端并发修改同一份 Bot 配置不在范围内。

未来客户端需区分本机待发送、Relay 等待、后台已接纳与回答或拒绝状态；网络投递队列只负责投递，不替代执行侧输入队列。UI 断线或手机进入后台只影响自身同步，后台行为受移动系统限制。配对、撤销、迟到控制与多端可靠性仍需专项设计与验证。

## 验收范围

首版只支持一个经过验证的后台发行版，启动时检查实际运行版本。不兼容时保留本地草稿、展示支持版本与修复指引并阻止发送，不自动升级或降级用户安装的后台。具体支持版本在连通实测后记录。

本机验收覆盖：Bot 创建与未就绪修复、初始化结果核对与指针保存恢复、模板与工作区固定、模板重启后重新装配、故障分类、归档与取消归档、历史保留、共享工作区，以及独立设置页的脱敏读取、保存冲突、密钥只写不读、目录刷新和当前模型选择。

生命周期验收分别验证：纯文本排队与撤回、未确认输入核对、停止后保留队列、再次发送与取消竞争、审批的信息与离线恢复、UI 退出后继续执行、显式停止后台和重开恢复。模板缺失、会话丢失与模型不可用均不得静默替换。

独立指令、Bot 记忆与附件各设后续验收阶段。真实模型、移动端、其他平台与签名交付分别报告，不从旧测试或开发环境结果推导；真实模型调用与中断工具恢复目前尚未验收。

## 范围外

多端正式交付、独立目标管理、永久删除与磁盘清理、模板编辑器、执行中立即插入输入、外部消息渠道、定时触发、主动推送、多后台调度与迁移、自动记忆整理与检索、自动跨 Bot 协作、群组、开机自启均不在首版范围，另行设计与验收。
