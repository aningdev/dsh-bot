# Relay 只转发端到端密文，且首版只支持双方在线

远程协作需要跨网络连接家里的 Runner，但聊天正文、工具结果、文件内容和审批决定都属于用户的私人数据。把 Relay 做成可信中继意味着运维方可以读取这些内容，攻击面也随之扩大。

因此业务内容在客户端与 Runner 之间端到端加密，Relay 只处理连接、路由和在线状态；模型凭据始终留在执行侧。首版 Relay 只支持客户端与 Runner 同时在线，不承担离线请求的存储与稍后投递，因此客户端在未取得接纳确认时必须保留结果未知状态，而不是假定失败。

代价是无法借助 Relay 做离线消息补发，设备离线期间的请求由客户端自行保留为待发送内容；加密、配对与重放保护仍需选定经过审查的协议或库，具体实现待验证。依据见 [产品蓝图](../PRODUCT_BLUEPRINT.md) 和 [Host 与客户端调研](../HOST_AND_CLIENT_RESEARCH.md)。
